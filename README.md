# God's Plan · Labs

Herramientas, cursos y juegos web de God's Plan, juntos en un solo lugar.

**Sitio:** https://labs.godsplan.dev

## Qué hay aquí

| Carpeta | Qué es | Antes estaba en |
|---|---|---|
| `index.html` | Menú principal de Labs | — |
| `finanzas/` | Finanzas personales: ingresos, gastos fijos, deudas, préstamos y límite diario (Firebase) | godsplan-finanzas · finanzas.godsplan.dev |
| `capital/` | Shadow Ledger: libro mayor con dashboard, gráficas y estados de cuenta (Firebase) | godsplan-capital · capital.godsplan.dev |
| `velocity/` | Overdrive: prueba de velocidad al escribir con ranking global (Firebase) | godsplan-velocity · velocity.godsplan.dev |
| `coding/` | Cursos de HTML5, JavaScript, Python y SQL | godsplan-coding · coding.godsplan.dev |
| `canvas/` | Secure Canvas: pegar HTML y ver la vista previa | godsplan-canvas · canvas.godsplan.dev |
| `games/` | 10 juegos: 2048, Víbora, Buscaminas, Memorama, Palabra, Gato, Sudoku, Crucigrama, Arrow Zen y Crimson (Sudoku y Crucigrama usan Firebase) | godsplan-games · games.godsplan.dev |
| `assets/` | Estilos, script y fuentes del sistema de diseño de God's Plan (copia de `godsplan-site/assets`) | — |

Los subdominios viejos (finanzas., capital., velocity., coding., canvas., games.) redirigen a su carpeta en Labs.

## Probarlo en tu computadora

No necesita instalación: abre `index.html` en el navegador.
